## Why Concepts?
Unlike most VEX frameworks, Antaeus tries to do things different. The unique
syntax allows for a lot of flexibility and power, but it also means that you
need to understand some new concepts before you can start using it. This section
will cover the most important concepts that you need to understand before you
can start using Antaeus.
