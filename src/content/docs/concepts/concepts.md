## Why Concepts?

Unlike most VEX frameworks, Antaeus tries to do things different. The unique
syntax allows for a lot of flexibility and power, but it also means that you
need to understand some new concepts before you can start using it. This section
will cover the most important concepts that you need to understand before you
can start using Antaeus.

## No-Code Style

This section of the docs aims to remain purely conceptual, meaning that it
should implementable in any runtime (Vexide, PROS, etc.), library (Antaeus,
Lemlib, etc.) or language (Rust, C++, etc.). Rather than creating code examples
for each and every possible combination, I have left it up to you to decide how
to implement these concepts. I have seen to many codebases patched to crudely
modified examples from docs and I hope that yours doesn't end up in the same
state. It's always important to remember that writing code is a better way of
learning than reading code.
